# Stickers

Концепт: доска стикеров на WebGL 2. Свои картинки становятся стикерами с белой вырубкой, их можно отклеивать за край, снимать целиком, переносить и клеить заново.

**Демо:** https://zaikopewpew.github.io/Stickers/

- Тяни за край — стикер отклеивается, видна подложка. Отпустил раньше — прилипнет обратно.
- Отклеил больше чем наполовину — стикер снят, неси куда угодно. За середину — просто перенос.
- Картинки: перетащи файлы в окно или вставь ⌘V. PNG с прозрачностью режется по силуэту, остальное — скруглённым прямоугольником.
- Колесо над стикером — размер, ⇧ + колесо — поворот, ⌫ — удалить (или бросить в корзину).
- Голографическая плёнка: радужные дуги, как на CD, ползут за курсором и переливаются на сгибе, под курсором — блёстки. 1–6 переключают эффект: блик, блёстки, призма, рябь, растр, голография.
- Звуки синтезируются в браузере: треск отклеивания по скорости, шлепок при наклейке.

Всё в одном `index.html`, без сборки. Стикеры хранятся в IndexedDB браузера.
